# ISSUE-018-T04 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 证券 Upsert、计数与批次 SUCCEEDED 同事务提交或回滚。

**Architecture:** PersistenceService 拥有数据集锁与完整事务；通用参与者在写入前后参加该事务。BatchCommitService 用 T02 三个低层入口复验许可并记录成功。

**Tech Stack:** Java 21、Spring JDBC / TransactionTemplate、JUnit 5、Testcontainers MySQL 8.4.6。

**Spec:** `docs/task-designs/ISSUE-018-T04-design.md` 全文，接口、顺序、失败和验收以此为准。

## Global Constraints

- 用最小代码实现；新增交付文件加入 Git。沿用当前分支，保留 T01–T03 暂存成果，不创建提交。
- 数据集锁→任务行→批次行；persist 两重载及 commit 拒绝外层事务。
- REQUIRED / 60 秒；同一 DataSource，persistence 不依赖 download/task。
- 不实现 worker、HTTP、配置、自动失败记录、重试或恢复；不改 V1–V8、40 项 YAML。
- 四条设计验证命令必须实际通过，专项 MySQL IT 不得跳过。

**Interfaces:** 产出 `PersistenceParticipant.NONE`、`void beforeWrite()`、`void afterWrite(WriteCounts counts)`，以及 `WriteCounts persist(AdaptedBatch batch, PersistenceParticipant participant)`。旧入口委托 NONE。

- [x] 先写真实空批回调事务测试：`assertThat(service.persist(empty, participant)).isEqualTo(new WriteCounts(0, 0))`；回调写审计表并记录同一连接，返回后独立连接能读到两条记录。运行 core 专项观察缺少类型 / 重载红灯。
- [x] 入口拒绝外层事务，验证 batch 后仅 `rows.isEmpty() && participant == PersistenceParticipant.NONE` 快速返回；持锁覆盖 TransactionTemplate.execute 全部提交 / 回滚过程。
- [x] 事务内顺序为 `beforeWrite(); findExisting(); WriteCounts.from(); upsert(); afterWrite(counts);`，空批仍执行回调。
- [x] 按专属设计补齐回调前 / 后与第二 JDBC 批失败回滚、外层事务两入口与空批拒绝、空 NONE 无 DB 快速返回、提交前持锁 / 失败释放 / 事务开始失败 / 同步未启用测试；保留原有效回归并更新公开重载断言。

### Task 2: 批次原子成功提交

**Files:** 新增 core `download/task/BatchCommitService.java` 与 `BatchCommitServiceIT.java`。

**Interfaces:** 消费 Task 1 的 persist 重载；构造器 `(PersistenceService, DownloadTaskRepository, Clock)`；公开 `WriteCounts commit(ExecutionPermit permit, UUID batchId, AdaptedBatch batch, long sourceRows)`。

- [x] 先用真实 V8 和 `commit_test__prices` 建 RUNNING SINGLE 任务 / 批次，写成功和空批测试，观察缺少 BatchCommitService 红灯。
- [x] 拒绝外层事务和非法入口参数；`findTask` 短事务预查许可 / 数据集 / 截止。回调先 `lockTask` 再 `lockBatch`，复验身份与截止；afterWrite 用一次时钟调用 `succeedBatch`。返回前不调用 finishTask / failBatch。

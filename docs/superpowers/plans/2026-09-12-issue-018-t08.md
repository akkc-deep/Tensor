# ISSUE-018-T08 Implementation Plan

> **For agentic workers:** Use test-driven-development and dispatching-parallel-agents for the bounded service, coordinator and configuration work below. Keep the existing branch and stage new files without committing, as required by the task handoff.

**Goal:** Implement manual retry/resume and a single-worker lifecycle that recovers database facts only after actual execution exits.

**Architecture:** DownloadTaskService owns the shared admission/coordination lock. DownloadTaskCoordinator reserves a lease before dispatch and retains it until the runnable exits. An explicitly registered lite Spring configuration supplies lifecycle integration without enabling production HTTP.

**Tech Stack:** Java 21, Spring, JDBC, MySQL 8.4.6, JUnit 5, Testcontainers.

**Spec:** `docs/task-designs/ISSUE-018-T08-design.md` (complete task-specific implementation and test matrix).

- Use real MySQL 8.4.6 for persisted transitions; explicit IT execution is required.
- New files enter Git; no automatic commit. Complete T08 before designing/preparing T09.

**Goal:** 从持久化任务地址查询详情、叶子批次和版本控制的手动操作。

**Architecture:** 扩展现有 task API/DTO；一个 composable 串行调度查询周期和控制；Vue 页面与批次表只展示服务端事实。复用现有视觉和下载页缓存。

**Spec:** `docs/task-designs/ISSUE-018-T11-design.md`（全文已读）。入口交接：`docs/task-handoffs/ISSUE-018/ISSUE-018-T11-handoff.md`。

## Global Constraints

- 保持 `feat/download-by-date-range` 工作区、既有暂存成果；新增文件加入 Git，不自动提交。
- 不改后端、生产能力、旧同步 API、共享 HTTP、依赖版本或普通 e2e fixtures/config。
- int64 使用 bigint，控制体是精确十进制 JSON number token。
- 详情与批次独立快照；不使用固定百分比，查询失败不改任务状态。
- 运行 2000ms，失败 5000/10000/30000ms；隐藏暂停，单周期、旧响应隔离。
- 本项浏览器证据为受控交互；真实生命周期/普通 e2e/发布门禁属于 T12，真实完整性属于 T13。

# ISSUE-018-T05 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** 所有 Tushare 客户端请求共享预算预约、节流和完整交换的停止 / 时限控制。

**Architecture:** 实例 gate 串行保护完整 operation，完成后再计最小间隔。RestClient 局部 attribute 将 context / clock 交给请求包装器，创建独立 JDK 请求超时；调用者取消并 join 虚拟 I/O 线程后释放 gate。

**Tech Stack:** Java 21、Spring 6.2.19、JUnit 5、WireMock / 本地 HttpServer。

**Spec:** `docs/task-designs/ISSUE-018-T05-design.md`（全文已读取，具体算法和测试矩阵直接遵循该设计）。

## Global Constraints

- 默认最小间隔 1500ms；显式 0 合法，更慢配置不得绕过；六参数属性构造器保留。
- beforeRequest 恰好一次且在任何等待之前；停止优先于截止；预算不退还。
- 每次等待不超过 min(100ms, 剩余时限)，节流使用单调时间，截止使用 UTC。
- 所有 I/O 结果路径 join 实际线程；错误无原始 cause / suppressed / secret，不捕获 Error 冒充业务错误。
- 保留旧 JSON、身份校验、64 MiB 上界、无自动 retry、RestClient 注入；不增加依赖、不实现 T06 或 worker。
- 沿用当前分支和既有暂存成果；本任务文件加入 Git，不自动提交已有工作。

# ISSUE-018-T10 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** 按能力提交持久化下载任务，可靠恢复未确认提交并显示服务端近期任务。

**Architecture:** 独立任务 API/DTO 保证 int64 无损；useDownloadFlow 管理元数据和提交的独立生命周期；useDownloadTaskList 管理分页和可见性轮询，页面只接线并复用既有视觉组件。

**Tech Stack:** Vue 3 / Element Plus / Axios / Vitest / Node 24.15.0 / npm 11.12.1。

**Spec:** `docs/task-designs/ISSUE-018-T10-design.md`（完整接口、状态机及测试合同）。

## Global Constraints

- 保留当前 `feat/download-by-date-range` 工作区；新增文件加入 Git，不自动提交。
- 最小实现；不改后端、依赖、全局 HTTP、旧同步 API/DownloadResult、生产 RANGE 门禁或全站视觉。
- T10 仅提供 `/downloads/tasks/{taskId}` 链接；T11 实现详情与控制，T12 接续普通 e2e。
- task int64 使用 bigint，必须在原始 JSON number token 上验证整数和边界；禁止先舍入后转换。
- 存储先于 POST；不确定请求沿用原 submissionId/参数，恢复先于元数据和普通列表。

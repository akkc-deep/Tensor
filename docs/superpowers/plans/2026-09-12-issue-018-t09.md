# ISSUE-018-T09 Implementation Plan

> **For agentic workers:** Use test-driven-development and dispatching-parallel-agents for the bounded independent domains below. Preserve the branch, stage new files, and do not commit automatically.

**Goal:** Expose durable task HTTP admission, queries and manual controls, wire production lifecycle, and observe committed events safely.

**Architecture:** Controllers consume Service/QueryService only. Strict Bound/Replay binding preserves historical idempotency; Repository captures immutable events in the existing transaction and publishes afterCommit. One production runId and properties object feed existing Service/Runner/Coordinator.

**Tech Stack:** Java 21, Spring Boot, Jackson, JDBC, MySQL 8.4.6, JUnit 5, Testcontainers, JSON Schema 2020-12.

**Spec:** `docs/task-designs/ISSUE-018-T09-design.md` (complete field, behavior, error and test contracts).

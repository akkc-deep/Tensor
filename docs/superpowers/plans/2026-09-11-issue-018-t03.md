# ISSUE-018-T03 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 本地接收持久化下载任务、幂等找回与一致历史查询。

**Architecture:** 接收服务组合既有注册表、参数校验和独立事务仓储。查询服务仅依赖仓储，详情只读一次 snapshot。DTO 使用内嵌 record。

**Tech Stack:** Java 21、Spring JDBC、Jackson、JUnit 5、MySQL 8.4.6 Testcontainers。

**Spec:** `docs/task-designs/ISSUE-018-T03-design.md`（全文为接口、顺序、错误和验收的绑定要求）。

## Global Constraints

- 用最小代码实现。将创建的文件加入 Git 版本控制。
- 保留当前工作区已暂存的 T01/T02 成果；不创建提交或变更分支。
- 不导入 app / Web / Tushare；不启动 worker、HTTP 或 retry / resume 转换。
- 不调用 download、downloadBatch、plan、assess、adapt 或 persist。
- Settings.defaults(): true / 100 / 36600；参数 8192 UTF-8 bytes，批次 / 策略 16384 bytes。
- 所有公开用例拒绝调用方已有事务；接收锁在仓储事务之前取得。

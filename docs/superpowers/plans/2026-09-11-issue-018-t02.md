# ISSUE-018-T02 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 按已完成的 T02 设计提供任务与批次持久化、受限快照、条件转换及可靠数据库事实。

**Architecture:** 核心固定 JDBC 仓储拥有高层事务；仅三个 T04 参与方法加入外层事务。显式 JSON schema 与不可变记录保持插件合同和数据库边界；V8 独立添加任务表。

**Tech Stack:** Java 21、Spring JDBC/TransactionTemplate、Jackson databind、MySQL 8.4.6、Flyway、JUnit 5/Testcontainers。

## Global Constraints

- 完整规格：`docs/task-designs/ISSUE-018-T02-design.md`；既定接口、DDL、失败规则及验收值以该文档为准。
- 不修改 V1–V7 或证券数据集注册；生产 51 表 / 7 迁移，测试 52 表 / 8 迁移，40 个注册证券数据集。
- 参数 8192 / 16384 字节、策略 16384 字节，以紧凑规范化 UTF-8 计算；读取前 128 KiB 防御限制、嵌套深度 16。
- 高层事务拒绝已有事务；写 REQUIRED、读 REPEATABLE_READ/readOnly，均 60 秒；时间按 UTC 毫秒写入。
- 保留当前分支及 T01 暂存成果；新增文件加入 Git；本次不启动 T03、worker、HTTP 或上游访问。

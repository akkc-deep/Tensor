## 表格规范

- 中文字段名称默认单行，技术标识通过“字段名”按需显示；保留完整标题提示、单位、原字段顺序与来源列。
- 同一列的表头和正文共用宽度与对齐方式：文本左对齐，日期居中，数值区域居中且内部按小数点对齐。
- 正文 14px，左右留白各 14px；桌面标准行高 44px、紧凑 38px、舒适 52px，窄屏紧凑至少 40px。桌面默认表头 46px，展开技术标识后 60px。
- 列宽按字段类型、表头、实际文本与等宽数字尺寸决定，不将所有列强制等宽；高精度值需要时扩展整列。
- 数字保留原始精度、符号、末尾零和负零，不转为 JavaScript Number；用显示层留白对齐，复制时仍是单段完整数值。
- 固定首列、表头与正文同步滚动；宽表在内部横向滚动，长文本可通过点击和键盘查看全文。
- 翻页时列宽保持稳定；字体切换或完成加载后按实际字形重新测量。

## 三页功能与落地边界

数据查看按“数据源与数据集 → 筛选 → 表格 → 分页”组织。保留证券代码、日期、查询、重置、分页、行高选择，以及加载、空结果、失败和重试状态。

数据下载采用连续的配置与结果区域。选择接口后显示对应参数，提交后原位呈现等待、成功、空结果或失败；保留原参数重试及请求标识，返回计数直接显示，不做递增动画。

设置页保留主题颜色、HEX、自定义颜色校验、实际应用色、浏览器保存状态、恢复默认，以及字体、动效和表格密度。主题联动作用于整体界面，涨跌与错误语义独立于主题色。

正式实施复用 Vue 3、Element Plus、公共组件和现有主题机制，遵循最小代码原则。以届时已合入的区间下载与元数据契约为准，保留所有真实参数及接口能力，不把 Demo 的合成数据、模拟等待或计数接入生产。

不新增任务历史、监控指标、后台任务、图表或无真实依据的进度百分比。用户已有主题偏好继续保留；锁定的是当前视觉方向，不代表清空生产偏好。

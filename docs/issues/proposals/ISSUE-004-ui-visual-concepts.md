# ISSUE-004：数据工作台 UI 最终方案

方案状态：已确认，作为前端实施与验收依据。

关联问题：[前端 UI 不美观，缺乏科技感](../problems/ISSUE-004-ui-visual-redesign.md)。

## 方案入口

[最终方案 HTML](ISSUE-004-ui-visual-concepts.html) · [数据下载](ISSUE-004-ui-visual-concepts.html#download) · [数据查看](ISSUE-004-ui-visual-concepts.html#dataset) · [设置](ISSUE-004-ui-visual-concepts.html#settings)。

HTML 是本方案的交互与视觉参考，包含完整样式、脚本和示例数据，可直接在浏览器中离线打开。正式前端以本方案实施，继续使用现有 Vue 3、Element Plus 和 API 客户端。

## 设计目标

采用具有科技感的证券数据工作台风格，以清晰的信息结构、冷色层次、统一组件和精确的数据排版提升操作效率。布局与主题颜色独立，换色不改变控件位置、组件尺寸、信息层级或当前操作状态。

## 页面布局

- 全局导航：桌面采用固定宽度的左侧导航，包含品牌、数据下载、数据查看和设置入口，当前页面有明确选中态。
- 设置页：通过侧边导航进入，当前仅包含“外观与主题”，集中提供主题取色器、HEX 输入、“应用”和“恢复冰川白”。主题控件仅在设置页展示。
- 数据下载：左侧为下载配置，右侧为本次结果；数据源和接口并排，接口说明、请求参数、提交操作分组呈现。
- 数据查看：上方为数据源、数据集和筛选条件，下方为完整数据表格与分页。
- 日期输入：开始日期和结束日期为两个独立控件，分别选择和编辑；校验必填要求及日期先后顺序。
- 表格：证券代码列固定，宽表格在内部横向滚动；数字对齐，涨跌通过正负号和颜色共同表达。
- 窄屏：导航与内容纵向排列，下载配置和结果依次呈现，表格保持内部滚动。

## 全局主题

主题颜色在“设置 → 外观与主题”中调整。设置完全由前端管理，不读取或写入后端，不进行账号或跨设备同步。进入设置并返回业务页面时保留日期、筛选条件、分页和操作状态。

用户选择一个颜色，系统生成整套浅色主题，联动页面背景、侧栏、面板、边框、文字、按钮、链接、焦点、品牌标识与选中态。面板和背景保持清晰的浅色层次，成功与错误颜色保留固定语义。

- 取色器即时应用；HEX 输入使用 `#RRGGBB`，点击“应用”生效。
- 非法 HEX 显示就地错误，保留当前主题。
- 过亮主色自动调整为可读的较深颜色，保留用户输入并显示实际应用色。
- 主色在页面、面板、导航、悬停表面和选中背景上的对比度目标至少为 5.5:1，同时检查主按钮与白色文字的对比度。
- 主题通过公共 CSS 变量应用，并映射到 Element Plus 主题变量。
- 偏好保存在当前浏览器的 `localStorage` 中，刷新和切换下载、查看、设置页面后保持一致；不依赖后端接口。
- 本地存储不可用时仍可即时预览，提示“仅本次预览”。
- “恢复冰川白”恢复整套默认颜色，并保存默认偏好。

## 业务交互

数据下载保留数据源与接口选择、元数据驱动参数表单、参数校验、提交、结果展示及重试能力。结果展示上游返回数、插入数和更新数。

数据查看保留数据源与数据集选择、元数据驱动筛选、查询、重置、分页和每页条数调整。表格展示业务列与 `source_plugin`、`source_api`、`ingested_at` 来源列。

两个页面统一提供待操作、加载中、成功、空数据和错误状态。加载时明确禁用相关操作；错误说明原因并提供适用的重试入口。文字清晰、键盘焦点可见，遵循减少动画偏好。

## 接口与实施约束

- 实施范围为前端，后端接口路径、HTTP 方法、参数、响应结构、状态码、错误码及语义保持不变。
- 数据源、接口、参数、数据集和筛选条件继续由现有元数据驱动，正式页面覆盖全部已接入的数据集。
- 查看页的开始和结束日期沿用现有日期范围筛选契约。
- 下载区间由前端组织现有接口调用；对于仅接受 `trade_date` 的接口，拆分为单日期请求，不向后端新增开始或结束日期参数。
- 保留现有业务能力、参数校验、错误处理与分页规则，不新增依赖后端支持的监控指标、后台任务或任务历史。
- 遵循最小代码原则，统一公共布局、组件状态和主题变量，复用现有技术栈。

## HTML 参考文件边界

HTML 使用本地样例演示交互，不调用后端或写入业务数据。底部状态预览工具条仅用于展示方案中的页面状态，不进入正式产品。

表格取自 [daily.json](../../data-template/daily.json) 与 [weekly.json](../../data-template/weekly.json) 的前 24 行，记录数明确标为示例值。数值保留样例原值：日线 `pct_chg` 为百分数，周线样例为比率，例如 `-0.0378` 约为 `-3.78%`；表头标注单位，`pre_close` 显示为“前收盘价”。样例缺失的来源列显示“—”。

下载计数按首次写入场景示意；日期区间包含样例日期 `2026-08-07` 时显示成功，否则显示空结果。这些样例结果不代表真实下载已执行。

## 验收标准

- 正式页面符合 HTML 参考文件的布局、视觉层次和主题规则。
- 自定义主题使背景、侧栏、面板和操作色整页联动，布局及操作状态保持稳定。
- 侧边导航可进入设置页，主题控件集中在“外观与主题”；设置操作不发送后端请求，往返设置与业务页面保留原有操作状态。
- 主题输入校验、刷新恢复、跨页面同步、存储不可用时的降级及完整重置有效。
- 开始和结束日期独立输入，下载、查询、筛选、重置、分页、重试及各类反馈状态正常。
- 桌面及窄屏没有页面整体横向溢出，宽表格内部滚动可用。
- 文字、控件和焦点可辨识，主题满足对比度要求。
- 前端构建、相关功能回归与接口兼容验证通过。

HTML 主题检查入口：在已安装前端依赖及 Playwright Chromium 的环境中运行 `node scripts/verify-ui-concept-theme.cjs`。

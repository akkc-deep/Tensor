# ISSUE-004：前端 UI 不美观，缺乏科技感

## 当前阶段

最终设计已确认，待制定实施计划。

设计依据：[数据工作台 UI 最终方案](../proposals/ISSUE-004-ui-visual-concepts.md) · [HTML 参考文件](../proposals/ISSUE-004-ui-visual-concepts.html)。

## 问题与目标

现有前端的视觉表现需要整体提升。重新设计页面布局、信息层级、配色、字体、间距及组件状态，形成具有科技感的证券数据工作台，同时保留现有业务能力和后端接口。

## 最终方案

- 桌面使用固定宽度的左侧导航，包含数据下载、数据查看与设置入口。
- 下载页采用左侧配置、右侧结果的分栏布局；查看页采用上方筛选、下方表格与分页的布局。
- 默认冰川白配色，自定义主题色联动背景、侧栏、面板、边框、文字与操作色，布局与颜色独立。
- 主题颜色调整集中在“设置 → 外观与主题”，设置仅由前端管理，不与后端交互；往返设置与业务页保留日期、筛选条件、分页和操作状态。
- 主题偏好在当前浏览器保存，支持 HEX 校验、自动对比度调整和恢复默认配色；成功与错误保留各自语义色。
- 日期使用独立的开始日期与结束日期控件。
- 统一待操作、加载、成功、空数据、错误、禁用及键盘焦点状态。
- 窄屏采用纵向布局，宽表格在内部滚动。

## 实施约束

- 前端位于 `control-plane`，沿用 Vue 3、Vite、Element Plus、现有 API 客户端和元数据驱动能力。
- 不修改后端接口路径、HTTP 方法、请求参数、响应结构、状态码、错误码及语义，不新增后端接口依赖。
- 保留数据源与接口选择、动态参数表单、下载结果、数据集筛选、表格展示、分页及重试能力。
- 下载区间由前端组织现有单日期请求，查看日期沿用现有范围筛选契约。
- 正式页面使用现有接口提供的数据，HTML 参考文件中的样例值仅用于方案展示。
- 遵循最小代码原则，复用现有技术栈和公共组件。

## 关闭条件

- 最终方案已在正式前端完成实施，主要页面具有统一、清晰且有科技感的视觉效果。
- 设置导航、整页主题联动、本地偏好保存、独立日期输入及各业务场景功能正常；设置操作无后端请求。
- 后端接口及契约保持不变，前端继续通过现有接口完成业务操作。
- 桌面和窄屏布局可用，文字、控件、宽表格与键盘焦点可辨识。
- 前端构建、相关回归与接口兼容验证通过，验收结果已记录。

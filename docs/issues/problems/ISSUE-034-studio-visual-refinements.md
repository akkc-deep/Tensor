## 整体视觉判断

当前采用克制的蓝灰色工作台风格，白色内容区、浅色侧栏和细分隔线形成了清楚的区域关系。配色、标题和边框整体协调，值得保留。最影响精致度的是宽屏下的对齐断层、侧栏信息占比，以及部分控件的尺寸与图标差异。

## 优先调整项

以下沿用原审查的优先顺序；“现状”指调整前的截图，“建议”是当时的审查意见。

### 1. 宽屏下，面包屑与页面主体脱离同一对齐轴

- **位置：** 下载工作台、数据查看、外观设置顶部。
- **视觉影响：** 中。
- **现状：** 宽屏截图中，标题和内容整体居中，面包屑仍靠近屏幕左边缘，与下方标题形成明显的横向错位。
- **原因：** 属于同一页面的路径、标题和内容出现两套起始位置，削弱了版面的连续性。
- **建议：** 面包屑使用与页面主体相同的最大宽度、居中方式和左右内边距；与标题之间建议保持 20–24px。顶部全局导航可保持现有布局。
- **调整后检查：** 宽屏下，面包屑首字、页面标题和主体容器左缘落在同一垂直线上。

### 2. “最近任务”底部辅助信息占比偏大

- **位置：** 下载工作台右栏，任务列表下方。
- **视觉影响：** 中。
- **现状：** 宽屏截图仅显示一条任务，但下方总数、页码说明、操作提示、更新时间、每页数量和翻页控件连续排成多层，辅助区域比单条任务本身更高。
- **原因：** 内容权重被排版面积倒置，右栏的视觉重心落在列表说明和分页上。
- **建议：** 将总数与页码说明合成一行；将每页数量与翻页控件放在同一行；提示和更新时间归为一组，建议组内间距 4–6px、组间 12–16px。任务名称保持较深颜色，辅助信息保持现有灰蓝色，无需继续淡化。
- **调整后检查：** 第一眼先看到任务名称和状态；底部信息形成两三个紧凑分组，不再像另一段任务列表。

### 3. 目录筛选控件的高度和箭头样式不统一

- **位置：** 下载工作台左栏，数据源、搜索框和“全部”下拉框。
- **视觉影响：** 中。
- **现状：** 三个连续控件呈现高、中、低不同高度；“全部”的箭头更黑、更靠边，与数据源选择框的细灰色箭头差异明显。
- **原因：** 同一小区域出现不同的尺寸节奏和图标语言，容易产生组件拼接感。
- **建议：** 左栏三个控件统一为建议 36px 高，左右内边距统一为 12px，垂直间距统一为 8px；两个下拉箭头统一尺寸、颜色和右侧留白，圆角沿用现有小圆角。
- **调整后检查：** 三个控件形成整齐的纵向序列，文字垂直居中，两个箭头看起来属于同一套组件。

### 4. 短表单被横向拉得过长，主按钮形成过重的色带

- **位置：** 下载工作台中央，股票代码、交易日期和“开始下载”。
- **视觉影响：** 中，属于比例微调建议，不作为必须遵守的设计规则。
- **现状：** 两个内容较短的输入框横跨中央大部分宽度，“开始下载”也铺满整行，成为页面面积最大的高饱和色块。
- **原因：** 控件面积与实际文字量差距较大，中央显得松散，按钮的色块重量又明显高于其他内容。
- **建议：** 保留三栏结构，优先将短表单内容宽度限制在建议 600–720px，并与接口标题左对齐；主按钮可试用建议 160–200px 宽，保留现有蓝色和高度。先对比截图，再决定是否调整中央栏宽。
- **调整后检查：** 代码、日期和按钮形成紧凑的视觉组；按钮仍明确醒目，但不再像横贯整个工作区的横幅。若收窄后右侧留白更突兀，应回调宽度。

### 5. 设置页的小齿轮单独占行，标题区域显得零碎

- **位置：** 外观设置页，“外观与主题”标题上方。
- **视觉影响：** 低。
- **现状：** 页面标题和说明之后，又依次出现独立齿轮、分区标题、分区说明；小图标悬在两组文字之间。
- **原因：** 一个分区标题被拆成多个视觉停顿，纵向层级偏碎，也与下载页图标紧邻标题的处理不同。
- **建议：** 将齿轮移到“外观与主题”左侧，建议图标 16–18px、图文间距 8px，垂直居中；说明放在标题下方，建议间距 6–8px。
- **调整后检查：** 齿轮、标题和说明被自然看作一个整体，页面主标题仍保持最高层级。

## 建议保留

- 蓝色主操作、深蓝灰文字和浅灰蓝背景的配色关系，当前没有明显颜色冲突。
- 下载页白色中央区与浅色两侧栏的区分，区域清楚，无需增加更多卡片或阴影。
- 中文名称搭配较小的等宽接口标识，适合当前数据工具场景。
- 数据表的数值右对齐、细横线分行，以及导航的细下划线选中态。
- 设置页的简洁留白；内容较少本身不构成必须填满页面的问题。

## 统一调整方向

沿用现有蓝灰工作台风格，优先统一页面对齐轴、同类控件高度和辅助信息分组。字体继续采用当前体系，可将页面标题、分区标题、正文和辅助信息分别收敛到建议 24/18/14/12–13px；间距以 8px、16px、24px 为主要档位。主色集中用于主要按钮、选中态和链接，继续保留浅边框、小圆角和少阴影的组件表达。

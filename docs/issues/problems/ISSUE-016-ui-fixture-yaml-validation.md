# ISSUE-016：UI 测试 YAML 解析器缺少严格字段校验

## 当前状态

新增，未解决。2026-09-07 从 ISSUE-004 最终审查的非阻塞延期项拆出，当前已登记，待后续解决方案。ISSUE-004 保持已解决，本问题独立跟踪。

## 问题与证据

涉及 [ui-redesign.fixtures.js](../../../control-plane/e2e/ui-redesign.fixtures.js) 的 `parseColumn`，该函数读取生产 YAML 的单行列声明，为浏览器测试构造模拟 API 数据。

源码核对发现：

- 正则只匹配 `COLUMN_KEYS` 中的属性，没有验证整行内容是否完整解析；未知属性可能被吸收到相邻字符串值，或被跳过，而没有立即报错。
- 匹配结果直接写入 `column[pair[1]]`，重复属性可能覆盖前值，没有单独拒绝重复键。
- 后续必填属性、类型、列数和顺序检查不能替代完整的字段与语法校验。

来源见 [ISSUE-004 正式验收记录](../../verification/ISSUE-004-ui-redesign.md#独立审查与收尾)。原最终项目审查范围为 `50eaa24..041ab9a`，将此项判定为非阻塞 Minor，接受独立延期处理。

## 影响范围

该解析器仅用于 UI 测试输入。现有49项生产配置已核对只使用支持的键，本轮验收未受影响；正式后端和业务运行不使用这个解析器。

未来扩展列配置时，测试可能使用错误的模拟元数据而未及时失败，降低回归结果的可信度。

## 关闭条件

- 完整校验限定的单行映射格式，遇到未知属性、重复属性或未解析内容时明确报错。
- 补充未知字段、重复字段及非法格式的反例，并保留合法标量和列表值的覆盖。
- 现有49项配置继续正确生成模拟元数据，字段名称、标签、类型、数量及顺序保持一致，相关浏览器回归通过。
- 保持修改限于测试解析器及其验证，不修改生产 YAML 或业务契约，不扩展为通用 YAML 解析器。

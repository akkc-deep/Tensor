## 问题与证据

本次查看了 ISSUE-004 的三页桌面截图、下载与查看窄屏截图，并核对当前布局、样式及组件。以下是视觉与布局判断，不是新发现的业务故障，也不把上一轮测试通过等同于本轮美感达标。

| 问题 | 现有证据 | 对使用体验的影响 |
| --- | --- | --- |
| 页面定位重复，操作区出现偏晚 | 导航、69px 工作空间栏、大标题及说明、面板标题层层叠加；[查看桌面截图](../../verification/ISSUE-004-ui-redesign/datasets-desktop.png)中表头约从 y=660px 开始 | 高频查看数据时，首屏大量空间用于介绍和配置 |
| 下载配置与结果的视觉权重不匹配 | [下载桌面截图](../../verification/ISSUE-004-ui-redesign/downloads-desktop.png)使用大双栏；结果区最小高度 346px，主要内容只有状态和三项计数 | 界面显空，提交前的操作焦点不够集中 |
| 边框与容器承担过多层级表达 | 面板、分隔线、输入框和表格边线普遍使用同一个 `--tensor-line`；主要容器统一 14px 圆角 | 视觉更接近通用表单后台，内容本身不够突出 |
| 说明信息的展开方式拖长操作路径 | [下载窄屏截图](../../verification/ISSUE-004-ui-redesign/downloads-mobile.png)中接口中文说明、接口名、分类、查询方式逐项纵排；查看页也有独立的大型配置面板 | 少量输入需要较长滚动，窄屏数据结果出现过晚 |
| 字体层级和控件规格缺少统一收敛 | 正文及说明多处为 12–13px，大标题最高 38px；全局仅主按钮强制 44px，查看页查询与重置按钮高度不同 | 重要内容与次要说明的阅读节奏不稳定，细节显得拼接 |
| 字体依赖系统默认，缺少针对中文数据工具的选型与字样验收 | 根字体为 `system-ui` 等系统回退，项目未携带字体文件；品牌、状态标题分别使用 650、550 字重，表头技术标识为 11px | 中文、英文和数字的比例与字重由平台决定，视觉风格缺乏可控的一致性 |
| 缺少贯穿操作流程的动效设计 | 当前业务源码未定义统一 transition、keyframes 或页面切换过渡；已有减少动画规则，选择器等主要沿用组件库自身反馈 | 导航、弹层、提交与结果呈现缺少共同节奏；具体流畅度仍需下一轮动态预览验证 |
| 表格列宽没有充分区分内容类型 | `DatasetTable.vue` 的 `minWidth` 仅区分入库时间 180px、长文本 240px、其他列 140px | 代码、日期、短数值和高精度金额使用过于相近的起始宽度，部分列空、部分列挤 |
| 表格对齐与单元格节奏缺少完整规范 | 已有数值右对齐与等宽数字，但业务代码没有统一定义表头槽位、单元格留白、正文行高及不同小数位的视觉对齐 | 用户反馈对齐度差；需按表头、内容、固定列及滚动状态整体重做，不能只补一个 `text-align` |
| 设置页内容与容器比例失衡 | [设置桌面截图](../../verification/ISSUE-004-ui-redesign/settings-desktop.png)用较大的分区展示少量主题控件 | 主题选择缺少直观样张，留白没有服务操作 |

源码入口：`control-plane/src/style.css`、`layouts/AppLayout.vue`、`components/common/PageHeading.vue`、`components/download/ApiDescription.vue` 及三个业务视图（后三类路径相对 `control-plane/src`）。截图来自 2026-09-07 的合成数据验收；当前前端源码没有未提交差异，已核对上述布局特征仍存在。本轮未重新运行浏览器或真实下载。

## 改版目标

形成清晰、精致、适合持续操作的证券数据研究工作台。布局、字体、动效和表格排版作为四个共同验收的设计主项：改善构图与内容密度，校准中英文字体及数字排版，设计操作反馈与状态衔接，按内容重新分配列宽、行高、留白与对齐，让用户更快看到并准确比较数据。

推荐方向为“数据优先的研究工作台”：紧凑导航、单层页头、中性浅色表面、克制的蓝色操作强调；查看页以表格为主体，下载页以连续的配置与结果回执组织内容。具体布局和尺寸目标见提案，均为待评审建议。

## 范围与约束

- 覆盖公共导航、数据下载、数据查看、设置，以及选择器、日期控件、表格、分页、状态反馈和响应式布局。
- 字体范围包含字体选型、真实字重、字号与行高、中英混排、数字对齐、加载及回退；动效范围包含导航切换、控件反馈、弹层、提交结果衔接及减少动画模式。
- 表格范围包含表头与正文对齐、文本／日期／数值的分类规则、不同小数位的显示对齐、内容驱动列宽、行高与内边距、固定列及宽表滚动；保留所有字段和完整数值。
- 沿用 Vue 3、Vite、Element Plus、现有 API 客户端及元数据驱动表单，遵循最小代码原则，复用现有公共组件和主题实现。
- 保留下载、查询、重置、分页、原参数重试、精确数值和单位、来源列、键盘操作及跨页状态保留。
- 保留设置页自定义主题、整页配色联动、HEX 校验、对比度调整、本地保存和存储失败提示；改版不能退化为只改变按钮颜色。
- 下载日期与参数以实施时已合入的元数据和契约为准，与进行中的区间下载工作核对；本 issue 不改变后端能力、参数语义或请求次数。
- 不新增监控指标、任务历史、后台任务、图表或无后端依据的进度百分比，不扩展为框架迁移。

## 运行说明

生产运行使用 Java 21、MySQL 8.4 和同版本生产 JAR／说明／smoke 脚本，参见[首次运行](../runbook/first-run.md)和[配置说明](../runbook/configuration.md)。当前说明中的生产迁移为 V1～V5、V7 共六次、49 张业务表；schema 级权限为 CREATE、SELECT、INSERT、UPDATE、ALTER、INDEX。Token 仅后端注入，缺少 Token 时可首跑和查询、不能下载。根 health 200/UP 才表示就绪，readiness 不能替代数据库检查。

[验收包说明](../runbook/acceptance.md)仅用于独立验收库；验收包附加 fixture/V6，七次迁移、50 表，不能作为生产分发物或连接生产库。已有 V7 升级须停写并验证备份，旧包不兼容新主键，不能只回退 JAR。

代理响应预算至少 130 秒；Spring 70 秒是每阶段停机上限，外部终止窗口须覆盖全部阶段和清理。正常停止使用已核实进程的 SIGTERM；备份恢复和外部 TLS／访问控制按 runbook 处理。以上是现行操作说明的引用，不是本任务执行记录，也不构成发布就绪声明。

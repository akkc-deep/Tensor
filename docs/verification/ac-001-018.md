# Tensor v1 AC 与需求证据映射

归档日期：2026-09-07；任务 [M14-T08](../task-handoffs/tensor-v1/tensor-v1-task-board.md#m14-t08)。配套[发布清单](release-checklist.md)记录各证据原日期、提交/JAR、命令、退出码、计数、文档当前 SHA-256 与风险处置；[发布摘要](release-summary.md)给出交付结论。

## 映射口径

原要求逐字取自 [PRD v1.0](../design/Tensor_多源证券数据平台_PRD_v1.0.md) §7、§10、§12.1；直接／部分／内联关系沿用[需求追踪索引](../traceability/tensor-v1-requirements.md)。追踪索引的 Evidence 只是计划责任，不是已经通过的证明。本表从实际报告单独判断内联要求，没有因关联 AC 存在而推定内联全部满足。

“已有证据支持”仅对引用的原版本和场景有效；“部分支持”表示只验证部分要求或存在直接证据缺口；“无可用证据”表示所读来源不足以直接证明该要求，并不判定实现必然缺失。覆盖程度不等于本次验收结果。所有行均为本次未复验，不能将不同包／专项结果相加为同一候选通过。

E01～E16 与发布清单一一对应，同号链接直接进入原来源。E04/E05、E12/E13 虽共用来源文件，分别代表不同运行；E16 的有效首跑结果在看板完成记录，进入交接不是结果。AC 原表未单列 P0/P1，不能人为给 AC 添加优先级；功能需求保留 PRD 的 30 项 P0 与 PRD-F-014 的 P1，非功能保留追踪索引的“发布门禁”属性。用户对 ISSUE-008/009 的“不依赖”只调整当前适用范围，不改写 PRD 原要求。

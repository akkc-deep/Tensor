# Studio 后端接入版 Demo

仅适配和验收 PC 桌面浏览器。

在 `control-plane` 中使用 Node 24.15+（24.x）运行 `npm run dev`，打开 <http://127.0.0.1:5173/studio-live.html>。

沿用原版 Studio 的布局和样式，使用正式 `/api/v1` 请求层。Vite 将请求代理到 `http://127.0.0.1:8080`；其他后端地址通过 `TENSOR_BACKEND_URL` 配置。后端启动方式见 [首次运行说明](../../../../docs/runbook/first-run.md)。页面不保存后端地址或凭证。

## 已接入

- 数据源、接口目录、搜索分类和真实下载能力；按后端参数生成单次／日期范围表单。
- 创建真实后台任务，复用提交标识、本地待确认记录、结果找回与原请求重发逻辑。
- 任务列表每 5 秒刷新，隐藏或离开下载页暂停；按状态、数据源、接口和提交标识组合筛选，支持每页 20／50／100 条服务端分页。
- 详情读取真实批次、返回行数、新增／更新次数；批次支持五种状态筛选、拆分父批次及父子标识查看、每页 20／50／100 条分页；运行中详情每 2 秒刷新，关闭后停止；按服务端权限和版本重试／恢复。
- 数据集定义、条件查询、完整字段、来源列、精确数值和每页 20／50／100 条分页。
- 外观主题选择；仅影响本页，刷新后恢复默认。

## 与原 Demo 的差异

任务状态筛选采用后端提供的六个状态，不合并成跨状态分组。“更多筛选”中可输入数据源、接口和提交标识，点击“应用筛选”后生效；支持查找已停用数据源的历史任务。翻页、轮询和页大小变化沿用已应用的条件，不发送尚未提交的输入。筛选或页大小变化会回到第一页。

日期轴、批量可用性和完整性说明来自能力接口，不使用 `demoBatch.js`，不在前端拆分批次。批次默认只显示最终执行批次；勾选“显示拆分父批次”后可查看已拆分记录。批次筛选和列表总数由服务端计算；包含父批次时，列表数量可能大于任务执行批次数。“已中断”仅是任务状态，不是批次状态。

任务和数据查询不使用 `catalog.json` 或模拟定时器；连接失败会展示错误及重试入口，不回退到示例数据。下载和重试／恢复会实际执行，成功结果留在后端数据库。

原版 `/ui-demos.html` 和正式控制面入口继续可用。此入口是迁移前的可运行适配版本，不表示 `STUDIO-T01` 至 `STUDIO-T10` 已完成。

## 验证

在 `control-plane` 中运行 `npm test` 和 `npm run build`。`LiveApp.spec.js` 验证请求接线：单次／范围参数、能力限制、连接失败、提交结果不确定后的原标识重发、精确版本重试／恢复、完整数值和查询分页快照，以及任务／批次筛选、页大小和父批次展示。请求层和状态测试覆盖合法参数、旧请求隔离，以及翻页、轮询、重试后的筛选保留。

启动前端开发服务后，运行 `PLAYWRIGHT_BASE_URL=http://127.0.0.1:5173 npm run test:e2e -- studio-live.spec.js`，验证 1280／1440 像素桌面下的筛选、分页和详情弹窗。此测试拦截全部 API 请求，使用受控契约响应，不依赖真实后端。

浏览器联调可直接读取本地后端已有任务和已入库数据；创建／重试操作的组件测试使用受控响应，测试不会调用真实 Tushare 账户。
